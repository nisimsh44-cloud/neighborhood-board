# Neighborhood Board 🏘️
Web application for neighborhood community board – posting and viewing local ads.

## Features
- Public viewing of posts
- User registration and login (bcrypt password hashing)
- Post creation, editing, and deletion
- Admin management of posts and users
- Secure input handling (SQL Injection & XSS prevention)

## Tech Stack
- Backend: Python (Flask)
- Database: PostgreSQL / SQLite
- Frontend: HTML, CSS, JS
- Version Control: GitHub + Jira integration
